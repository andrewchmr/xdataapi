# Examples

| File | Framework |
|---|---|
| `langchain_tool.py` | LangChain (Python) tools over the REST API |
| `crewai_tool.py` | CrewAI (Python) tools over the REST API |
| `vercel-ai-sdk.ts` | Vercel AI SDK tools over the `xdataapi` npm package |

Agents that speak MCP need none of these: connect `https://api.xdataapi.io/mcp` directly.
Set `XDATAAPI_KEY` from https://xdataapi.io/dashboard.
